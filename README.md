# Rumbo

Landing page de Rumbo, plataforma de talento juvenil de Chontal Noxus.

## Desarrollo local

```bash
npm install
npm run dev
```

## Produccion

```bash
npm run build
npm run preview
```

Para abrir el build con Live Server, ejecuta primero `npm run build` y abre `dist/index.html`.

Cada push a `main` ejecuta el workflow de GitHub Pages en `.github/workflows/deploy.yml`.

La landing usa el logo oficial, el kiosco y el diseno de tarjeta entregados por el equipo dentro de `src/`.
