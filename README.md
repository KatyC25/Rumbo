# Rumbo

Landing page de Rumbo, plataforma de talento juvenil de Chontal Noxus.

## Desarrollo local

```bash
npm install
npm run dev
```

## Produccion

```bash
npm run build
npm run preview
```

Cada push a `main` ejecuta el workflow de GitHub Pages en `.github/workflows/deploy.yml`.

El logo vectorial actual es un placeholder de navegacion. Cuando se entregue el logo oficial, se puede reemplazar el componente `Brand` en `src/App.jsx` sin cambiar la estructura de la pagina.
